### Auth — how to get in (no token UI exists)

MA 2.11 has **no API-token screen**; the Settings grid has no such card. Auth is username+password,
exchanged for a JWT:

```
POST http://172.16.1.31:8095/api
{"command":"auth/login","args":{"username":"<user>","password":"<pass>"}}   ->  .access_token
then:  Authorization: Bearer <token>
```

The JWT lasts **90 days** (`iat` 2026-08-31 → `exp` 2026-11-29), so it satisfies D-39's "long-lived
token" requirement. **Log in per run rather than caching the token** — a cached one expires silently
and `check-music-consumers.sh` is meant to run unattended for months.
