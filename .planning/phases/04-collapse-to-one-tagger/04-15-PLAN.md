  **not** `config/scripts/`.

  `extended.conf` carries a trailing comment. Use the anchored form `grep -c '^ReplaygainTagging="false"'`
  (04-12 deviation 1). Never edit `extended.conf` to satisfy a grep — its sha256 and mtime must be
  unchanged, and that is itself an assertion.

  `"false"` cannot satisfy (04-12 deviation 3). It is not a prerequisite failure.

  UNKNOWN, never "absent", and it is recorded as a non-zero `_rc` field in the OBS block.

  Assert existence, then compare a count against an independently measured count.

  string contains neither the watcher's name nor its path (04-12 deviation 6: building the pattern from
