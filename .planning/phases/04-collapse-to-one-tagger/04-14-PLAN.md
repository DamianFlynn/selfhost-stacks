<objective>
Fix the instrument that blocked ROADMAP Phase 4 success criterion 3, and prove it can fail before a
real music job is spent on it.

Criterion 3's behavioural half is OPEN (`04-VERIFICATION.md`, `04-D12-EVIDENCE.md` § 6) for a reason
that is structural and measured: SABnzbd moves a finished job into `complete/nzb/music/` and **then**
invokes the post-processing hook, so 04-12's watcher — which polled that destination tree — could
never sample before the hook. Job A's first sighting was 12:18:00.074Z against a `Matching` line at
12:17:59Z (already later); job B's snapshot fell inside the same one-second `Audio.txt` bucket as its
own `Matching` line (indeterminate). On top of that the contract's 2-second stability floor cannot
fit inside job A's 1-second hook.

Purpose: this plan replaces the timestamp race with a **structural ordering**. A snapshot taken while
the job folder is still under `incomplete/` is necessarily earlier than the move, and the move is
necessarily earlier than the hook — no sub-second comparison against a second-resolution log is
needed. An instrument that has already produced one invalid measurement has earned a self-test, and
real music jobs are scarce (one chance each), so the fix is driven against synthetic fixtures —
including a control that must return **FAIL** and a control that must return **UNPROVEN** — before
the window is armed.

Output: two host-scratch scripts (`watch-d12b.sh`, `judge-d12b.sh`) with their sha256 recorded, a
four-control self-test transcript, and a dated in-band amendment to `04-D12-EVIDENCE.md` §§ 1 and 5
written **before** any second job exists.
</objective>

- Everything this plan runs on LXC 100 (`root@172.16.1.159`) is READ-ONLY over the estate: `stat`,

  tmpfs on LXC 100 and 1.1 GB there once took the whole box down.

- This repo is public. Job folders and release names never enter a tracked file; they are identified
  by the first 12 characters of the sha256 of the folder basename, and the mapping lives only in host
  scratch (04-12 precedent, T-04-12-01).
- Remote commands are bounded **Linux-side** with `timeout` inside the remote string (macOS has no GNU
  `timeout`); any remote string containing a pipe starts `set -o pipefail`, and the ssh RC is taken on
  the very next line with no local pipe in the assignment.
- `wc -l` on a missing path prints nothing and exits 1, which a `$(...)` capture renders as `0`
  (04-12 deviation 2). Assert a path exists before reading an absence from it.
- `pgrep -f <pattern>` matches the inspecting shell's own command line when that command line contains
  the pattern or the path (04-12 deviation 6). To assert a process is gone, write the pattern to a
  file and match it with `grep -F -f` over a `ps` snapshot captured to a second file.
