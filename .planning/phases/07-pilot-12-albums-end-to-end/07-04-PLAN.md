<objective>
Make the DJ-routing mechanism D-08 chose a reviewable, reusable instrument rather than an ad-hoc
command, and register its real-library `beet` invocations deliberately in the D-04 exemption
register (D-27), driving the register's undriven overlay-key half both ways while natural material
exists (DEF-06-21-06).

Purpose: E1 — the mechanism does not exist; Phase 6 supplied `albumtype=dj` by hand and that may not
be cited as evidence. D-08 rejects a global `import.set_fields` (it would stamp every bucket-A
import) and a hook plugin (new Python in a pre-release app during the phase that first grants
`rw`). Phase 9 routes DJ content in volume, so the operation belongs in `scripts/`, where the D-04
scan sees it. A D-08 call against the real library cannot be compliant by construction (it must
open `/config/library.db`), so it is registered, and `D04_EXEMPT_BASELINE` moves with a named
reason. ⛔ The prohibition D-27 states is on raising a pin to make a run green without a registered
reason — not on moving it with one. `D04_DOC_BASELINE` stays at 2: prose in any `*.md` that
describes this operation is phrased so it is not invocation-shaped (06-16's precedent).

This plan writes nothing to the estate: the script is created and statically checked; its first
`--apply` is plan 07-13's, behind that plan's gate. `--apply` is never run here.

Output: `scripts/route-dj-album.sh`, the extended register, and a drive transcript.
</objective>

reach once `albumtype=dj` is set (rule 2 if `disctotal >= 2`, else rule 3), and exit 0.

`--apply` — in order, stopping at the first non-zero RC (each RC read and printed):
(a) repeat (1) and (2); (b) read `"$BEET_REALLIB" modify -h` and assert it offers the no-move flag
(`-M`/`--nomove`) and the confirm-skip flag (`-y`) — refuse with exit 3 if either is absent,
naming which; (c) `"$BEET_REALLIB" modify -a -M -y album_id:N albumtype=dj` (album-level so every
item inherits; `write: yes` writes the field into the files); (d) `"$BEET_REALLIB" move -a -p
album_id:N` and print every ` -> ` line; (e) `"$BEET_REALLIB" move -a album_id:N`; (f) re-run the
`ls` of (2) with `$albumtype|$path` over items (`ls -f '$albumtype|$path' album_id:N`) and assert
every item reads `albumtype = dj` and every path begins `/media/Music/DJ/`; exit 1 if not.

Error handling: exit 2 usage, 3 could-not-look/refusal, 1 a post-condition failed, 0 success.
No `set -euo pipefail` at top level if it would turn a checked RC into a silent exit — check each
RC explicitly instead. No credential is used. `bash -n` and `shellcheck` (if installed; a missing
shellcheck is recorded as not run).
Do NOT run the script against the live container in this plan in either mode — the read-only
mode needs an imported album to be meaningful (library holds 0 items), and `--apply` belongs to
plan 07-13's gate.
