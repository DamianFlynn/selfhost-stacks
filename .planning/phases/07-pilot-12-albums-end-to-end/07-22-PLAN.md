these writes. The MA add-on has no snapshot or export path in this estate (precedent: the 07-15 sync
was equally unfenced, T-07-22-01). The residual risk is accepted because MA is downstream of beets,
which is fenced by `@pre-07-18`: its library state is re-derivable by a filesystem re-sync. The Task 2
gate must repeat this to the operator before any sync or refresh.
