import leaves each file byte-identical to its staged copy. The modify is the first write.
Method: LXC 100 /root/phase07-0713/sim0713.py and sim0713b.py, run as `docker exec -i -u 568 beets-flask
/venv/bin/python -` with BEETSDIR=/config (the live config read, import.write True, id3v23 False). Each copies
