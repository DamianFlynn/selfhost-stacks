<objective>
Prove undo on the cheapest possible album at the cheapest possible moment (D-15): back P01 out with
the mechanism the operator will actually reach for (D-14, `UNDO IMPORT`), prove it reverses the
tree, the database AND beets' `incremental` state, re-run to the identical good state, and then
release the Phase 6 snapshot whose release condition this event is (D-17) — only when the undo's
three paired witnesses AND the re-run's equality are both on record; every other outcome holds it
for plan 07-16's operator gate.

Purpose: criterion 5's own reason — rolling back one of tree/state without the other leaves the
release invisible to a retry — is exactly the half `beets.md` flags: `UNDO IMPORT` was verified once
on tree and database, never on `state.pickle`. If it misses `state.pickle`, a re-run is silently
skipped under `incremental: yes` / `incremental_skip_later: yes`, and the re-run step here is what
detects it.

`state.pickle` is read by DECODING A COPY: `docker exec beets-flask cp /config/state.pickle
/tmp/p7-state.<stage>.pickle` then `/venv/bin/python -c` unpickling the copy and printing whether
the staged P01 source path (the `_inbox/02-review/<folder>` container path, as bytes/str) is in
`state['taghistory']` (and any other top-level key, listed) — the live file is never opened for
writing. Its sha256 is recorded at every stage too. **The key is not assumed** (G-02): the fence
safety copy `/mnt/fast/safety/phase07/fence/state.pickle` (taken by 07-09 before any import) is
decoded the same way (copied into the container's `/tmp` with `docker cp`, never into `/config`),
and the entries the P01 import ADDED — the set difference post-import minus fence, per top-level
key — are the `P01 STATE KEY(S)` that the undo must remove. The staged path is only the
expectation; the set difference is the measurement.

⛔ `zfs [r]ollback` of `fast/appdata/arrs` is forbidden on every branch (Sonarr/Radarr/Lidarr state);
a file restore from `/mnt/fast/appdata/arrs/.zfs/snapshot/pre-07-pilot/beets/config/state.pickle` is
the only database/state remedy, and only on the operator's explicit answer. ⛔ No ZFS rollback of
`tank/media/Music` is planned either (the evidence map registered `UNDO IMPORT` as the rollback
mechanism). ⛔ `tank/downloads@pre-phase5` untouched (E4, D-17).
</objective>
