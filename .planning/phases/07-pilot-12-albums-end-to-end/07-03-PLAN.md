- Header: purpose (criterion 7 / IMPT-02 / D-25, Phase 9 criterion 2 inherits it); where it runs;

  `IMPORT_SWEEP_DB` default `/config/library.db`, `IMPORT_SWEEP_TIMEOUT` default 120. Any
  non-default value prints "override in effect — this run cannot report the sweep green" and
  forces a non-zero exit.
- **Dumper (remote half):** one `timeout "$IMPORT_SWEEP_TIMEOUT" docker exec
  "$IMPORT_SWEEP_CONTAINER" /venv/bin/python -c "$PROG" "$IMPORT_SWEEP_DB"` (program passed as
  argv to python, database path as a positional argument, no shell interpolation inside the
  container). The program opens `sqlite3.connect('file:'+path+'?mode=ro', uri=True)`, selects from
  `items` the columns `id, path, album_id, mb_albumid, track, tracktotal, disc, disctotal` and
  joins `albums.albumtype` on `album_id`, decodes `path` (a BLOB) with
  `os.fsdecode`/surrogateescape, computes for any basename matching `\.[0-9]+\.[^./]+$` whether
  the same directory holds the suffix-stripped name ON DISK (`os.path.exists`, read-only stat),
  and prints one JSON object per item. Read the ssh/docker RC; an empty dump with RC 0 is a
  genuine empty library; RC non-zero or unparsable output is UNKNOWN.
- **Judge (local half, pure):** a function taking the NDJSON dump file and printing findings per
  class plus counters, using `jq`/`awk` only, so `--self-test` drives the identical code:
  class 1 = suffix-shaped AND sibling-exists → finding; suffix-shaped without sibling → counted
  `SUFFIX_NO_SIBLING` (printed with paths, not a failure); class 2 = album items (album_id not
  NULL) with empty/NULL `mb_albumid` and `albumtype` not `dj` → finding; DJ ones counted
  `DJ_ASIS_EXCEPTION`; singletons counted `SINGLETON_NO_ALBUMID`; class 3 = group by
  (album_id, disc): if the group's non-zero `tracktotal` values are not all equal → finding
  (disagreeing totals — never first-wins); if equal and `count(items) != tracktotal` → finding;
  groups with no non-zero tracktotal counted `TRACKTOTAL_UNCHECKABLE`. Vacuity: items == 0 →
  UNKNOWN; album groups > 0 but checkable class-3 groups == 0 → UNKNOWN.
- Output: `📊 5. Summary` heading literal, with the KEEP THIS HEADING LITERAL comment naming
  `quick-health-check.sh` as its reader; summary lines labelled `items read:`,
  `collision findings:`, `empty mb_albumid findings:`, `tracktotal findings:`,
  `DJ as-is exception:`, `singletons:`, `suffix-shaped, no sibling:`, `uncheckable album-discs:`,
  `UNKNOWN total:`, `FINDINGS total:` — labels chosen not to collide with the consumers fold-in's
  grep (`MA version|artist rows|FAILURES total`).
- Exit ladder in order: usage → 2; UNKNOWN > 0 → 3; FINDINGS > 0 → 1; overridden → 1; green line
