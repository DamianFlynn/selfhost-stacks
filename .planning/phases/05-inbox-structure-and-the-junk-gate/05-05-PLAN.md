    LXC 100's 126 G ext4 root. Watch df on / rather than on the pool. The output here is a few MB, so the
    constraint is real but not binding.

    ONE FFPROBE PER FILE. ffprobe takes one input file. A scan built with xargs -n 50 ffprobe silently
    produces nothing and exits clean — it cost a wasted pass during the phase discussion. Iterate the
    file list and invoke ffprobe once per file with a redirect from /dev/null so it does not swallow the
    loop's stdin, and a bare double dash before the path. Request JSON with format and stream information
    so the tag dictionary comes back whole.

    BUILD RECORDS WITH JQ, NEVER BY STRING CONCATENATION. Emit one NDJSON object per file carrying at
    minimum: absolute path, basename, size in bytes, and the tag values for album, disc, track, and
    whatever the file calls the disc and track totals. Album values in this collection contain commas,
    exclamation marks and a DOUBLE SPACE, and a TSV of them is one stray tab from silent misalignment.
    If a TSV is wanted for eyeballing, generate it FROM the NDJSON rather than instead of it.

    NORMALISE THE DISC AND TRACK FIELDS EXPLICITLY. The measured distinct disc formats are only three —
    "1/2" seen 2,361 times, "2/2" seen 2,339 times and "1/1" seen 46 times — so parse the "N/M" form into
    separate disc number and disc total, and do the same for track, recording both the raw string and the
    parsed integers. Where a total is absent, record null rather than guessing; a null must never silently
    become a zero in a later sum.

    RESUMABILITY. Use a done ledger, not a re-scan of the NDJSON. Load it once into an associative array
    on start and skip any path already present. Ordering within a file is: emit the NDJSON line, THEN
    append to the done ledger. A hard kill in that window re-emits one record on the next run; it never
    loses one. A file whose ffprobe exits non-zero goes to the FAILED ledger and is NOT written to done,
    so a re-run retries it rather than permanently skipping it. A raising file is never counted as
    "no change": conflating an exception with a no-op result is how Phase 1 produced six unearned passes.

    MANIFEST PARSE. Read the m3u and emit a second NDJSON, OUT_DIR/now-manifest.ndjson, with one record
    per entry carrying the raw line, the first path component (the volume directory name as the original
    rip had it), any CD subdirectory component, and the leaf filename. Do NOT attempt to derive a volume
    NUMBER here — that derivation belongs to plan 05-06 and must be reviewable. The m3u uses backslash
    separators, so split on backslash, not on forward slash.

    The script is READ-ONLY. It must not write, move, rename or delete anything under NOW_ROOT. Assert
    that by resolving NOW_ROOT with realpath and refusing anything outside
    /mnt/tank/downloads/complete/nzb/unsorted, and by never opening a file under NOW_ROOT for writing.

    EXIT-CODE CONVENTION, stated: 0 when every file produced a record and the failed ledger is empty;
    1 when at least one file failed and is named in the failed ledger; 2 on usage error or when NOW_ROOT
    or MANIFEST is absent.
