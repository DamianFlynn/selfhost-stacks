        jq -r '.changes.album.new // empty' now-album-dryrun.ndjson | sort -u | wc -l   ->  0

      whatever the file contains, including an empty one. The artefact was not reshaped to satisfy
      it. The same assertion against the real shape:
        jq -r 'select(.field=="album") | .new' now-album-dryrun.ndjson | sort -u | wc -l  ->  115
