<objective>
Run the gate's destructive half, once the operator has said yes.

D-11 corrected an earlier position: `99-quarantine` is a REVIEW-AND-DELETE queue, not an archive.
Deletion is the expected terminal state for junk, not a deferred maybe. The earlier "delete nothing"
position was rejected for a reason that still holds — nothing in this estate is scheduled,
`quick-health-check.sh` is manual-only by decision, so a dwell-then-purge policy would never fire. The
fix is to do the review now, not to keep the content forever.

This plan is `autonomous: false` by design. D-13's gate blocks BOTH the move and the delete, and the
gate is a read-and-approve-a-file step, never a sit-at-a-prompt step.

Purpose: satisfy INBX-02 and ROADMAP criterion 2 as amended, and close Phase 1's D-23.
Output: a swept and emptied junk set, a retired `lidarr-import`, and a per-row result record.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator approval file to irreversible deletion | The file content at approval time is the authorization token; its hash binds the yes to a specific list. |
| Live download tree to a list approved minutes earlier | SABnzbd writes at roughly one music job per 72 s, so an approved path can become a live job before the sweep runs (TOCTOU). |
| Music project scope to SABnzbd's in-flight work and to the library | `incomplete/` and `/mnt/tank/media` sit on the same pool and one bad path constant reaches both. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-04-01 | Tampering | Irreversible deletion of operator data with no recovery | mitigate | `tank/downloads@pre-phase5` taken in plan 05-01 and proven by a file the sweep refuses to run without; deletion is per-row by name from the approved file, never over a glob |
| T-05-04-02 | Tampering | The approved list is edited between the operator's yes and the sweep | mitigate | sha256 recorded at approval and re-checked immediately before the sweep; a mismatch aborts |
| T-05-04-03 | Tampering | TOCTOU — an approved path becomes a live download before it is deleted | mitigate | The script re-derives every row against fresh state immediately before acting and aborts the whole sweep on any conflict, rather than skipping the row |
