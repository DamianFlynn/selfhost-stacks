Apply the split, once the operator has approved the mapping, and capture the before-state the tag
write will be judged against.

D-07 makes this cheap and reversible in the right way: `_inbox` and `unsorted/` are the same dataset,
so each move is an inode-preserving rename — instant and free. The 115 volume directories are created
INSIDE the existing collection folder, so `unsorted/` stays the immutable source ARCHITECTURE Pattern 5
describes, and whole volumes are pulled into `_inbox/` in batches later, not in this phase.

because the split produces the per-volume folder that defines the grouping the repair applies to. That
also means the tree as it stands at the end of this plan is exactly the before-state for plan 05-09's
field-level diff — so it is captured here.
