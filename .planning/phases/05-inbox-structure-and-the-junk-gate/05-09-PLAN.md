bitstream, not the container — so writing a tag does not break the join key and Phase 7's field-level
diff can still compare these files against their before-state. That claim is true, but only because

trap was measured on. So the claim is not restated here; it is tested, and the test is the pilot.

with CD1 1-22 and CD2 1-22, the tags read 44 files with tracktotal 22 and 22, and the file count is 44 —
so a discrepancy there is unambiguous.

Output: canonical album across 115 folders, an apply record, an after-capture and a diff verdict.
