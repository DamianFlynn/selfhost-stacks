<objective>
Build the read-only audit that every later plan in this phase is graded by, then run it once to
record the before-state.

This plan is deliberately first and deliberately non-mutating. The phase's six roadmap criteria are
all assertions about host state; writing the assertion mechanism before making any change means
each subsequent plan turns a red line green, and the final plan re-runs the same script rather than
inventing a fresh check that happens to pass.

Purpose: WRIT-01 is unmeetable without a correct audit, and a naive audit reports a **false pass**.
`stacks/selfhosted/arrs/beets/beets.yaml` and `stacks/selfhosted/arrs/soulbeet.yaml` are both
commented out of `stacks/selfhosted/arrs/compose.yaml` (lines 39 and 36), so no running container
exists for either regardless of the rw mounts their YAML declares. D-08/D-26 specify
running-container inspection; that is necessary but not sufficient. The audit reports both classes,
separately.

Purpose (second): D-19 hard-codes `/mnt/tank/media/Movies`, `/TV`, `/Books` as narrowed mount
sources. Those names have never been verified against the host. A Docker bind mount whose source
path does not exist is silently created as an empty directory rather than erroring — narrowing
Radarr to a typo would quietly break it. This plan reads the real listing first.

Output: `scripts/check-music-freeze.sh` committed and executable, plus a baseline report, an
ownership census and a sidecar inventory under the fence directory.
</objective>
