<objective>
Prove the bounds fire. Do not exit on "configured".

CONS-04 is this project's definition of done and D-15 applies it here: a control that *reads back* is
not a control that *fires*. This estate has been burned by that substitution twice — 01-06's path-set
diff passed while 83 `.nfo` were rewritten in place, and 02-08's `exportfs -v` kept printing a line
for a mount the client was refusing. Plan 07 read the settings back from the API. That is the
standing check's job and it discharges nothing here.

Three things this plan proves that no API response can show:

**Segments actually land in the new place, and nothing lands in the old one.** The second half is
only meaningful **while the old volume still exists**. Run it after the deletion and the test is
vacuous — an empty path proves nothing. So the observation comes first and the deletion comes second,
as separate tasks, in that order. That ordering is D-10's and it is not negotiable.

**Segment deletion and throttling actually start.** `EnableThrottling: true` is inert unless
`IsPkeyPauseSupported` or ffmpeg ≤ 6.1 — a gate the API cannot show. This estate's
`jellyfin-ffmpeg 7.1.4` was probed with Jellyfin's own detection command and does carry the
`p pause transcoding` runtime key, so the throttler should start; "should" is not evidence. The
throttler also gates on File input, video, and `RunTimeTicks >= 5 minutes`, so the proof title must
be a film, not a music track or a clip.

**The quota refuses a write.** ZFS `quota` returns **`ENOSPC`** — "No space left on device" — which is
the errno the incident's 764 zero-byte files already signature, and the string every log grep in this
estate is built on. `refquota` would have returned `EDQUOT` / "Disk quota exceeded", which such a grep
silently misses; that is why plan 03 set `quota`. And the property being bought is not that playback
survives — it will not — but that **`/` does not move**.

Purpose: the phase's whole premise is that these controls hold when nobody is watching. Reading them
back is how the last three attempts would have signed off.
Output: two transcripts, and an anonymous volume that no longer exists.
</objective>
