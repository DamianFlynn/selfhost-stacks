# Phase 02.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Derived from `02.1-RESEARCH.md` § *Validation Architecture* (35 test rows).

**The governing rule for this phase (CONS-04, D-15):** a control that *reads back* is not a control
that *fires*. Every bound in this phase has two separate proofs — a cheap read-back that joins the
standing check, and a one-time firing proof executed with its transcript recorded. Neither
substitutes for the other. This project has been burned twice by the substitution: 01-06's path-set
diff passed while 83 `.nfo` were rewritten in place, and 02-08's `exportfs -v` kept printing a line
for a mount the client was refusing.

| Property | Value |

| **Framework** | Bash assertion scripts under `scripts/`. Exit-code convention is established at `scripts/check-music-freeze.sh:31-42` — every red finding increments `FAILURES` and the script ends non-zero; `--baseline` prints everything and always exits 0; usage error is exit **2**, distinct from a failed assertion |

| **Quick run command** | `ssh root@172.16.1.159 'bash /mnt/fast/stacks/scripts/check-jellyfin-transcode.sh'` *(new script — Wave 0)* |
| **Full suite command** | `bash scripts/quick-health-check.sh` |
| **Baseline mode** | `--baseline` on the new script, so the before-state is recordable while the bind, the quota and the settings do not yet exist |
| **Estimated runtime** | ~20 s quick (no transcode started); full suite ~60-90 s |
| **Summary anchor** | Must be declared literally in the new script (e.g. `📊 5. Summary`) carrying the same DO-NOT-RENUMBER warning the other two fold-ins have. `quick-health-check.sh` must treat a **missing anchor as UNKNOWN, not green** — the WR-09 defect, already found twice in this estate |

## Sampling Rate

- **After every task commit:** `ssh root@172.16.1.159 'bash /mnt/fast/stacks/scripts/check-jellyfin-transcode.sh'` — targeted, < 20 s, starts no transcode.
- **After every plan wave:** `bash scripts/quick-health-check.sh` — the full estate check including both existing fold-ins, so a regression in Phase 1/2 coverage surfaces here too.
- **Before `/gsd-verify-work`:** full suite green **AND** the three D-15 firing proofs executed once with transcripts recorded — TRAN-03 quota-fires, TRAN-04 deletion-fires, TRAN-04 throttling-fires.
- **Max feedback latency:** 20 s (quick), 90 s (full).
