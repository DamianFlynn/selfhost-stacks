<objective>
Build the standing check this phase's every other plan samples against, and get it onto the host.

`scripts/quick-health-check.sh` is 217 lines and contains **no disk check of any kind**. That is why
19 GB accumulated in an anonymous Docker volume over ~36 hours with nothing saying so, and `/` went
from 2.2 GiB free to zero while an unrelated approval gate was open. D-20 answers with a new
standalone script covering `/` headroom, the absent anonymous volume, the transcode quota and the
encoding values read back — matching the shape of `check-music-freeze.sh` and
`check-music-consumers.sh` exactly, so it stays runnable alone when debugging.

This plan builds the script and records its `--baseline`. It deliberately does **not** fold it into
`quick-health-check.sh` — that is plan 02.1-10, after the cutover, because folding in a check that
asserts the post-state would leave the estate's shared health check red for the whole phase, and a
permanently-red check trains the reader to ignore it (the 01-09 trap).

**Four things the cross-AI review changed about this script**, all applied here rather than
retro-fitted later:

1. **`JELLYFIN_SECRETS` is env-overridable.** Plan 02.1-10's third negative control needs to point
   the credential path at something that does not exist. As originally written it either could not
   run or required mutating the real `600 root` file — which is itself an invariant
   `check-music-consumers.sh` asserts.
2. **The dataset's *mounted* state is asserted, not assumed.** If `fast/transcode` is unmounted at
   LXC boot, `/mnt/fast/transcode` is a plain directory, the bind still works, the quota does **not**
   apply — and `zfs get quota` from atlantis still returns `53687091200` and reads green. This is the
   same class of boot-race Phase 2 spent a plan closing with the `mountpoint` export option.
3. **A Jellyfin API blip does not turn the shared health check red for the wrong reason.** The GET
   retries three times before failing, and an exhausted retry is reported as `UNREACHABLE` in a
   counter distinct from a bound violation. Still fail-closed (D-19) — what changes is that the
   reader can tell "could not look" from "the value moved", which is exactly the trap D-17 exists to
   avoid.
4. **The script refuses to run in default mode on macOS.** `df --output` is GNU-only.

Purpose: every later plan in this phase samples with this script after each task commit; without it
there is no feedback loop under 90 seconds.
Output: `scripts/check-jellyfin-transcode.sh`, a recorded baseline transcript, and a host checkout
level with `origin/main`.
