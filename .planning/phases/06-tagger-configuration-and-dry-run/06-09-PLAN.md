Write `scripts/phase06-oracle.sh`. It runs from the repo root on the workstation, ssh-delegates to LXC 100 and `docker exec`s into `beets-flask`. Carry all five shared patterns S1–S5.

**Header.** Purpose; "Where it runs"; usage (`--self-test`, `--baseline`, and a subcommand split if the operator-approval gate below is used); the exit-code convention stated explicitly; the override contract — every knob `${VAR:-default}`, every one can only make it redder, and the expected-tree path and the sample path are **plain constants, not overrides**, because an override on either could manufacture a pass. The header is the `--help` output.

**Step 1 — the throwaway library, from a COPY of the real one.** `%aunique{}` is evaluated against whatever library the item is in, and a bare throwaway cannot see collisions with the real 1,244-file library, so it would report *fewer* firings than a real import — on a library with 828 measured duplicate groups, a zero-firing report is the warning sign. So: copy `/config/library.db` to `/tmp/p6/lib.db` **inside the container**, and open the copy with flask's 2.12.0 (D-04: 2.13.1 opening a 2.12.0 db would migrate it). Assert the ORIGINAL's sha256 before and after. Record in the output which library the run used, because the aunique count is only meaningful with that label attached — and assert it is the same library `06-EXPECTED-TREE.txt`'s header names.

**Step 2 — the `-c` overlay.** Every invocation uses an overlay setting `library: /tmp/p6/lib.db`, `statefile: /tmp/p6/state.pickle` and `directory: /media/Music`. `-l` alone does NOT redirect `statefile:`, and a real import on a throwaway `-l` would still write the shared pickle. `directory` is `/media/Music` deliberately: that is what makes the printed destinations the real library paths CONF-03 is about, and `/media` is `:ro` so it cannot be written regardless.

**Step 3 — refuse to run against a dirty destination.** `/tmp/p6` must not already exist or must be empty. A wrote-nothing assertion against a dirty destination proves nothing.

**Step 4 — the BEFORE manifests (D-29 layer 2).** Reuse `manifest()` verbatim in shape: `LC_ALL=C find <subtree> -type f -printf '%p\t%s\t%T@\n' | LC_ALL=C sort` for metadata, and `LC_ALL=C find … -print0 | LC_ALL=C sort -z | xargs -0 -r sha256sum` for content. `%p %s %T@` catches path, size and mtime; the sha catches content; together they catch additions and deletions too, because a vanished or new path changes both listings. Take manifests over **every sampled source folder**. Take the stamp OUTSIDE the mounts. Add the D-29 layer 3 pair to the same manifest set: the real `/config/library.db` **and** the real `/config/state.pickle`.

**Step 5 — the as-is import into the throwaway.** Import the sampled folders with `-A` (as-is), `copy: no`, `move: no`, `write: no`, `autotag: no`. State the reason in the file, because it is a design decision and not an omission: as-is isolates the **path-template** variable, which is what this phase exists to test, and it makes the expected tree computable before the run. A match-driven tree is not pre-computable; CONF-05's *Now!* proof is therefore a separate class assertion in plan 06-12, not a row in the committed tree. For the DJ (S5) folders, add `--set albumtype=dj` so the `albumtype:=dj` path rule is exercised — and record, in the script's own comment, that `--set` is a CLI flag with no per-inbox equivalent in rc6's `InboxFolderSchema`, so the **mechanism** for real flask-driven DJ routing is an unowned gap registered for Phase 7 (OQ-2/C-6), and that Phase 6 proves the path rule, not the mechanism.

**Step 6 — the oracle itself.** `beet -c <overlay> move -p` and capture every line. Normalise the output into a plain sorted destination-path list for the diff: take the right-hand side of each ` -> `, handle the two-line narrow-terminal form, and sort with `LC_ALL=C`. Write the raw transcript AND the normalised list to the output directory; the raw one is what a reader checks the normalisation against.

**Step 7 — the positive control INSIDE the measurement**, because a census that cannot see something it is known to contain has not measured zero, it has failed to look:
- Every oracle line must contain ` -> ` (or the two-line `  -> ` form). A `--pretend` transcript fails this trivially, which is the point.
- The count of destination lines must **equal** the sampled audio-file count from `06-SAMPLE.md`. Not at least — equal.
- Read the `(N already in place)` line. `move_items` filters out items whose path already equals their destination; a silent 0-row output is the failure mode. Record N explicitly; on an in-place import it should be 0.
- The output must contain the substring `/media/Music/`. If it does not, the run measured something else entirely.
If any of these fails, the verdict is `UNKNOWN, not green` and the diff is NOT evaluated — an oracle that could not look must not produce a zero-diff by having produced nothing.

**Step 8 — the AFTER manifests and the three-layer verdict.**
- Layer 1 (library): structural, from `docker inspect` — the `/media` mount is `RW=false` on the flask container. Assert it, do not read it from the compose file.
- Layer 2 (source): `diff_manifest()` over every sampled folder, both `meta` and `sha`, with the three-outcome vocabulary — 0 identical, 1 CHANGED (the dry run was not dry), ≥2 COULD NOT COMPARE.
- Layer 3 (beets state): the real `library.db` and the real `state.pickle` sha256 identical before and after. Name both — `-l` does not cover the pickle, and `state.pickle`'s mtime moving during a run that was supposed to write nothing is the warning sign.
Plus the `-newer $STAMP` sweep with its could-not-look preflight (CR-02): `2>/dev/null || true` feeding a count is exactly how a failed `find` produced an empty result, a zero count and a green tick claiming the dry run wrote nothing.

**Step 9 — the diff against the committed tree.** `diff` the normalised destination list against `.planning/phases/06-tagger-configuration-and-dry-run/06-EXPECTED-TREE.txt`. Zero-diff is the pass. Print the diff in full on failure — both directions, so a missing line and an extra line are distinguishable.

**Step 10 — cleanup.** Remove `/tmp/p6` inside the container and assert it is gone. `/tmp` is tmpfs on LXC 100.

**`--self-test`.** Drive every fail-closed branch without docker, against synthetic fixtures: a transcript with no ` -> ` at all (must refuse and not evaluate the diff); a transcript with the right shape but the wrong line count; a transcript whose `(N already in place)` is non-zero; an unreadable source directory (blind preflight); a changed `sha` manifest (layer 2 CHANGED); an unreadable manifest pair (layer 2 COULD NOT COMPARE); and one fully correct case producing zero reds. ## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| oracle → the real `library.db` | The oracle must never open the real database. It opens a copy, and the original's sha256 is asserted unchanged. |
| dry run → `/mnt/tank/downloads` (`rw`) | The source mount is read-write. Only `write: no`, `copy: no`, `move: no` and a checksum manifest stand between a dry run and a real one. |
| committed expected tree → oracle verdict | A zero-diff produced by an oracle that emitted nothing is the failure mode the positive control exists to catch. |
