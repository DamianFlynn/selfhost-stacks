<objective>
Prove the sharpest trap in the criterion set actually fires, and that the configured setting actually defeats it.

Purpose: the ROADMAP calls `incremental` without `incremental_skip_later` "the sharpest trap in the set", and this project's standing rule — stated separately in Phases 2, 02.1 and 4 — is that reading a setting back is not proof it applies. `ImportTask.finalize()` calls `save_history()` on a **skipped** task unless `incremental_skip_later` is set, so one quiet pass permanently marks every hard album complete and the backlog becomes invisible rather than imported. This plan makes that happen on a throwaway, then makes it not happen, with exactly one key different between the two.

Output: `scripts/phase06-incremental-control.sh` with a `--self-test`, and a transcript showing both outcomes. Entirely offline inside the container's `/tmp`; nothing under `/mnt/tank/media` is touched and nothing under `/mnt/tank/downloads` is written.
</objective>

Both live in the container's `/tmp` (which is tmpfs on LXC 100 — keep them tiny; the estate has already killed SSH on both host and LXC by staging 1.1 GB of XML there). Every key that is not the variable is IDENTICAL between them:
- Arm A: `library: /tmp/p6a/lib.db`, `statefile: /tmp/p6a/state.pickle`, `directory: /tmp/p6a/tree`, `import.incremental: yes`, **`import.incremental_skip_later: no`**, plus `copy`/`move`/`write`/`autotag`/`quiet`/`quiet_fallback` set so the import is in-place, writes no tags, and skips.

`write: no` is essential — `/mnt/tank/downloads` is mounted `rw` and the source files must not be touched. Assert the overlays differ on exactly one key by diffing them and requiring a one-key difference; a diff of two lines that happens to include a stray whitespace change invalidates the control.

**Refuse to run against a dirty destination.** Before each arm: `/tmp/p6X` must not exist, or must be empty. A wrote-nothing assertion against a dirty destination proves nothing. Create it fresh, owned by `beetle`.

**The five steps, per arm.**
1. Prepare one throwaway folder under `/tmp/p6X/src` — copied from an already-duplicated backlog folder, never moved, with a before/after sha256 manifest on the source proving it was a copy.
2. Import it with the overlay, forcing a **skip**. `finalize` is not reached under `--pretend`, so this arm must be a real (in-place) import; the skip comes from `quiet: yes` with `quiet_fallback: skip`.
3. Read `taghistory` **out of the pickle**, not out of a log: load `/tmp/p6X/state.pickle` with python and print the `taghistory` set. Arm A must show the folder's path tuple present; arm B must show `taghistory` empty.
4. Re-run the same import. Arm A must report the folder skipped and offer nothing — that is the "permanently marked done" half. Arm B must **re-offer** it.
5. Assert the REAL `/config/library.db` and the REAL `/config/state.pickle` sha256 are unchanged across the whole run (D-29 layer 3). Take the baselines before arm A starts and compare after arm B finishes, and also between the arms so a change can be attributed.

**`--pretend` is used here for the one thing it does prove.** Step 4's "is the folder offered" question is exactly what `--pretend` answers, and it answers it without reaching `finalize`, which is the only place `save_history()`/`save_progress()` are called — so using it for step 4 cannot itself contaminate the state being measured. Write that reasoning into the file. Also write the prohibition: `--pretend` is **never** used as a tree oracle here or anywhere in this phase (D-33); it prints source paths and no destination.

**Fail-closed vocabulary throughout.** UNKNOWN sentinels initialised before anything runs; read every instrument's exit status and branch on 124 first; a `taghistory` that cannot be read is `UNKNOWN, not green`, never "empty". `manifest_compare()` with the three-outcome vocabulary: 0 identical, 1 differs, ≥2 could-not-compare.

Each must produce exactly its expected outcome. This is how the red branches are proven to fire.

**No knob may manufacture success.** Every override `${VAR:-default}`, and the pair of overlay paths are plain constants, not overrides.

| Boundary | Description |
|----------|-------------|
| throwaway overlay → the REAL `state.pickle` | `-l` does not redirect `statefile:`. Without a `-c` overlay naming it, a throwaway import writes the shared pickle and silently poisons `incremental` for the real library. |
| container `/tmp` → LXC 100 RAM | `/tmp` is tmpfs on LXC 100; the estate has already lost SSH on host and LXC to 1.1 GB staged there. |
| `/mnt/tank/downloads` (`rw`) → source files | A real import with `write: yes` would rewrite tags on the source. |
