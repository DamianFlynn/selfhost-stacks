   block comment promises separator anchoring; it does not — it said "content start, or immediately
   inside an opening quote", which is what the code did. The substantive blind spot is real, had no
   current instance in the tree, and is graded WARNING.

   supplied to the reviewer** — GC-04, GC-08, GC-09, GC-10, GC-15. Four (GC-04, GC-08, GC-09,
   GC-10) were verified during round-2 planning by opening the targets, and GC-15 at its correct
   citation. None was disputed. The register must say **who** verified each and **how**, because
   "unverifiable" and "false" are different words and the round must not let the first decay into
   the second — the adjudication's own verdict table records **zero** false findings.
