# WHY THIS FILE IS AT THE PHASE ROOT AND NOT UNDER artifacts/
# ------------------------------------------------------------------------------
# Every committed .txt and .tsv under .planning/**/artifacts/ in this repository
# is an OUTPUT recorded after the run that produced it. This file is an INPUT to
# the run it judges: it is the statement of what the tree is supposed to be,
# made before the tree exists, and its only value is the commit that predates
# plan 06-11. Filing an input beside outputs would blur exactly the distinction
# that makes the zero-diff non-vacuous, so it sits at the phase root and says so
# here. It is the first fixture of its kind in this repository
# (06-PATTERNS.md § "No Analog Found").
#
# FORMAT AND THE CONTRACT WITH THE DIFF
# ------------------------------------------------------------------------------
# A plain path list, one intended destination per sampled audio file, LC_ALL=C
# sorted — the most diffable form, and what plan 06-11's diff assumes. Every
# line that is not a path begins with '#'. ANY CONSUMER MUST STRIP '^#' BEFORE
# DIFFING, e.g.  diff <(grep -v '^#' 06-EXPECTED-TREE.txt) <(...)  — the header
# is part of the fixture's meaning, not decoration, so it is not moved out.
# The consumer is scripts/phase06-oracle.sh (built by plan 06-08, run by plan
# 06-11): it diffs the ` -> ` destinations of `beet move -p` against this file,
# and ZERO LINES OF DIFFERENCE is the pass.
#
# THE ROOT
# ------------------------------------------------------------------------------
# Paths are written CONTAINER-INTERNAL, rooted at /media/Music, because that is
# what `beet move -p` prints inside beets-flask (config.yaml `directory:
# /media/Music`). The host equivalent is /mnt/tank/media/Music — the flask mount
# is /mnt/tank/media -> /media with rw=false (D-05), so nothing here is
# reachable for writing during Phase 6 even in principle.
#
# HOW THE EXPECTED PATHS WERE DERIVED
# ------------------------------------------------------------------------------
# The committed `paths:` templates applied to EACH SAMPLED FILE'S OWN EXISTING
# TAGS, read through beets' own mediafile inside beets-flask (beets 2.12.0) —
# NOT to a MusicBrainz match. That choice is deliberate and it is what makes
# this file computable at all:
#   * the oracle's arm A imports AS-IS (`-A`), which isolates the path-template
#     variable — the thing this phase exists to test — from the matcher;
#   * a match-driven tree is not pre-computable, because the candidate set is a
#     network result that can change between the writing and the run. That is
#     why CONF-05's *Now!* proof is a separate CLASS ASSERTION in plan 06-12
#     rather than a row in this file.
# The rendering itself is a CLEAN-ROOM re-implementation of the small slice of
# beets 2.12.0 the stanza depends on (path-rule selection, PaddedInt(2), the
# ASIS album-artist plurality rule, FormattedMapping for_path, sanitize_path
# with config_default.yaml's `replace:` block, extension lowercased). It does
# NOT call beets to produce these paths. A fixture generated by the thing it
# judges cannot fail; a divergence between this file and `beet move -p` is a
# FINDING, which is the entire point.
# Script and audit trail at the fence: /mnt/fast/safety/phase06/
# (phase06-expected-tree.py, audit.json — one {stratum, rule, source, dest}
# record per line below).
#
# PRECONDITIONS THE RUN MUST MEET, or the diff is meaningless
# ------------------------------------------------------------------------------
#  P1. ALL TEN sampled folders are imported into ONE library. %aunique{} is
#      evaluated against whatever library the item is in, so a per-folder
#      library would silently drop the one predicted firing below.
#  P2. The two S5 (dj-mixes) folders are imported with `--set albumtype=dj`.
#      Without it they fall through to the `default` rule and land under
#      Mastermix/ and Various Artists/ instead of DJ/.
#  P3. The S7 folder is imported with `-s` (singletons). Without it beets makes
#      a one-track album and the `singleton:` rule — the FIRST key in the
#      stanza, written out precisely so it is reachable — is never exercised.
#  P4. Import is AS-IS (`-A`) and `import.write` is overridden to `no` through
#      the `-c` overlay. Phase 6 writes nothing.
#
# THE LIBRARY THIS TREE ASSUMES — READ THIS BEFORE JUDGING THE AUNIQUE COUNT
# ------------------------------------------------------------------------------
# %aunique{} is evaluated against whatever library the item is in, so the count
# below is only meaningful with the library it was computed against attached.
# It was computed against the REAL library's collision set (06-RESEARCH.md
# option (a)), and that set is EMPTY: /mnt/fast/appdata/arrs/beets/config/
# library.db holds 0 items and 0 albums, measured 2026-09-21 by a read-only
# sqlite3 open, sha256 fbbdde0c416e72b9884e56c562fd88eaa4da447926e1cb6cc17c3e04
# aee7da1a. Consequences, both of which plan 06-11 must honour:
#   * the oracle must still run against a COPY of that library.db, opened by
#     flask's 2.12.0 (D-04 — beets 2.13.1 opening a 2.12.0 database migrates the
#     schema under 2.12.0's feet), with the ORIGINAL's sha256 asserted unchanged
#     before and after (D-29 layer 3, alongside state.pickle
#     f6a9a1ad7aa553e42e53a8056fa80724785111180a5e2122be4f8732d1e4bc7c);
#   * because the real collision set is empty TODAY, 06-RESEARCH.md's option (a)
#     and option (b) produce the SAME count. That equivalence is dated: it stops
#     being true the moment Phase 7 imports anything.
#
# PREDICTED %aunique{} FIRINGS — D-16's "every folder where it fires is
# reported", captured at the earliest possible moment
# ------------------------------------------------------------------------------
# Exactly one ambiguous set exists, and it was DRAWN rather than chosen: the S1
# stratum's LC_ALL=C key took two different rips of Benson Boone / American
# Heart, 24-bit FLAC and MP3.
#   ambiguous set size 2 · albumtype empty on both · year 2025 on both
#   -> first disambiguator that separates the set: `label`
#   (a) .../music/Benson Boone-American Heart-...-OBZEN-xpost   (FLAC)
#       label is EMPTY -> _tmpl_unique returns "" -> no bracket:
#       /media/Music/Benson Boone/American Heart/
#   (b) .../music/Benson_Boone_-_American_Heart-WEB-2025-BENSONBOONE  (MP3)
#       label = "Night Street Records, Inc. - Warner Records Inc." ->
#       /media/Music/Benson Boone/American Heart [Night Street Records, Inc. - Warner Records Inc.]/
# %aunique{} renders "" everywhere else in this file, and %sunique{} renders ""
# on the single S7 row (one singleton in the library, so the ambiguous set is
# size 1).
#
# THE GUARD, AND IT IS A HARD ONE
# ------------------------------------------------------------------------------
# When NO disambiguator separates an ambiguous set, beets appends the NUMERIC
# DATABASE ID — " [123]" — which is not reproducible across libraries
# [beets/library/models.py@v2.12.0 _tmpl_unique]. A committed expected tree
# containing one is a landmine, not a fixture. This file contains ZERO bracketed
# integers that are not four-digit years; the generator raises rather than emit
# one, and plan 06-05's verify rejects the file if one appears. The draw carries
# the matching rule — reject the candidate, take the stratum's next eligible row
# by the same LC_ALL=C key, record the substitution in 06-SAMPLE.md's
# reallocation table — and it was armed and did not fire (0 rejects).
#
# THE RENDERING IS 02-05, NOT 2-05 — decided, and stated
# ------------------------------------------------------------------------------
# `disc` and `track` are both types.PaddedInt(2), so `$disc-$track` renders
# 02-05 where D-14's prose writes 2-05. 02-05 is ACCEPTED here: it sorts
# correctly, and the alternative %right{$disc,1}-$track breaks at disc 10.
# ⚠ THE EXISTING LIBRARY USES A THIRD CONVENTION — `CD 02-01 Artist - Title.ext`
# (e.g. /mnt/tank/media/Music/P!nk/TRUSTFALL (2023)/CD 02-01 P!nk - Dreaming.
# flac). Phase 6 DOES NOT reconcile the two. This file is the statement of which
# convention Phase 7 will produce, and the S6 rows below — drawn from the real
# library — are the clearest illustration: their SOURCE names carry the old
# convention and their expected destinations carry the new one.
#
