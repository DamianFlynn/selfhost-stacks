PART 1 — GC-01: the size sweep that establishes the ceiling
================================================================================================

The shipped shape was, at scripts/check-beets-config.sh:554 and :567 (pre-fix line numbers):

    if printf '%s' "$raw" | grep -qF -- "$forb"; then

under this file's `set -euo pipefail` (:111). `grep -q` exits the instant it matches; `printf` is
still writing; `printf` takes SIGPIPE and exits 141; `pipefail` hands 141 to the PIPELINE; the
`if` therefore evaluates FALSE. Direction: a substring that IS present is reported ABSENT — a
false GREEN over a live condition, not a false red.

Driven at increasing input sizes with the forbidden substring on LINE 1, both forms, both grep
paths reachable from a bash script on this workstation (both resolve to /usr/bin/grep):

PART 1b — the defect is POSITION-DEPENDENT, which is why case 7 anchors at the TOP
------------------------------------------------------------------------------------------------

Same 128 KiB input, pre-fix form, substring moved:

    match at TOP     bytes=131085   pipeline_rc=141  MISSED (false GREEN)
    match at BOTTOM  bytes=131085   pipeline_rc=0    FOUND (correct)

A bottom-anchored regression case would have ticked GREEN against the broken code and proved
nothing. Case 7 puts the substring in the first 25 bytes of the raw text for this reason.

================================================================================================
PART 2 — GC-01: the fix, and the self-test case that discriminates it
================================================================================================

Fix, at both sites (scripts/check-beets-config.sh):

    if grep -qF -- "$forb" <<<"$raw"; then

A here-string feeds grep from a temporary file. There is no writer to take SIGPIPE, no pipeline
for `pipefail` to propagate from, and the `if` reads grep's own status. `-F` is kept (the
substrings are literals) and the `--` end-of-options guard is kept (a substring beginning with `-`
must not be read as a flag). `LC_ALL=C` was deliberately NOT added: multibyte behaviour is
unchanged by this fix and changing two things at once would have destroyed the measurement.

`set +o pipefail` around the test was rejected: turning the option off weakens every other
statement in the same scope to buy one test.

New self-test case 7: `synthetic_correct_dump` prefixed by one top-level key whose double-quoted
scalar opens with the literal `Compilations` and is padded with `x` past the ceiling. Measured
raw size, asserted in band rather than assumed:

    case 7 precondition: raw dump is 71013 bytes, above the 65536-byte pipe-buffer ceiling

An under-65536 result is a self-test FAILURE, not a silent skip — a case that quietly shrinks
below the ceiling is a case that has stopped testing anything.
