INSTRUMENT NOTE 1 — grep is invoked BY ABSOLUTE PATH, every time
---------------------------------------------------------------
Every measurement in this file is taken with /usr/bin/grep. The workstation's bare `grep`
is a SHELL FUNCTION and has silently matched nothing in this phase before, over files whose
content was demonstrably present (recorded in plan 06-41). A tool that answers "no matches"
when it was never really consulted is the exact false-green shape this phase exists to
remove. Bare `grep` appears nowhere in this audit.

INSTRUMENT NOTE 2 — the `HEAD --` rule on every byte-identity claim
------------------------------------------------------------------
A bare `git diff --exit-code <path>` compares the working tree against the INDEX, not a
commit. With an edit STAGED it exits 0. This plan stages and commits while it runs, so every
byte-identity guarantee in this file is written `git diff --exit-code HEAD -- <path>`.

INSTRUMENT NOTE 3 — every zero-expecting recipe was DRIVEN against a control first
----------------------------------------------------------------------------------
A count of 0 from a recipe that can never match is worth nothing. DEF-06-45-04 is exactly
that defect: 06-43 SECTION O published a `grep -cF` with a bracketed needle, which can never
match the real token, and the true `0` it printed was not earned by the printed recipe.
Every zero-expecting count below is preceded by the SAME recipe run against a control that
DOES contain the thing being screened for, observed to return non-zero. See § DRIVES.
