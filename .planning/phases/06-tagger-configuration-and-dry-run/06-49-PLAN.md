 2. **Bound remote commands Linux-side.** macOS has no GNU `timeout`. Include the specific trap:

    REDDER.** Never use an override to silence a red. Overrides exist so a failure branch can be
    driven.

    guards in `quick-health-check.sh`. Each guard forces a **non-zero exit** when its knob is set

 7. **Credentials never enter argv.** Use `-H @<(printf ...)` process substitution or stdin; never a

 8. **Counted tokens are written bracketed — and only where something counts them.** State the rule

    published recipe writes the counted token in bracketed form (`EXIT-CODE BEHAVIOUR CHANGE[D]`,
