    Canonical example: the named-pair tagger census in `check-music-freeze.sh` — a bare count of two
    whose MEMBERS differ is a red, not a pass.

 4. **`${VAR:-default}` overrides are ADDITIVE ONLY — an override may only ever make a check
    REDDER.** Never use an override to silence a red. Note that overrides exist so a failure branch
    can be driven, and that every `_Q`-rendered knob in `quick-health-check.sh` carries a guard
    forcing a non-zero exit when it is set away from its default. Canonical examples:

    `quick-health-check.sh`.

    review asks for.)* A count that gates pass/fail and must be hand-moved in the same commit as an

    skip, and its named reference environment stated beside the base constant.

    hoist it into one shared helper. Reason: a single shared fence is one edit away from being wrong

    companion refusal: `phase06-oracle.sh` carries **no** cleanup `trap` anywhere, deliberately,
    because one would fire on the forensic could-not-look exits and destroy the evidence they exist
    to preserve (`DEF-06-39-02`).

 7. **Credentials never enter argv.** Use `-H @<(printf ...)` process substitution or stdin; never a
    command-line argument, never a here-string that lands in a transcript. Never echo a header value
    into an artifact. Canonical example: the Jellyfin key handling in `check-music-consumers.sh`.

 8. **Counted tokens are written bracketed — and only where something counts them.** State the rule
    and its **decided scope**, citing `DEF-06-48-02`: any file whose content is counted by a
    published recipe writes the counted token in bracketed form (`EXIT-CODE BEHAVIOUR CHANGE[D]`,

    Prose documents that no published detector counts — `ROADMAP.md` among them — are deliberately
