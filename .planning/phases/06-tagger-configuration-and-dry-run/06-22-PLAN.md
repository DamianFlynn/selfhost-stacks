<objective>
Close **GC-01**, the round-2 BLOCKER, and **GC-13**, the same-file INFO that shares its shape.

GC-01: `scripts/check-beets-config.sh` runs `set -euo pipefail` and tests both forbidden-substring
lists with `printf '%s' "$raw" | grep -qF -- "$forb"`. `grep -q` exits on first match, `printf`
takes SIGPIPE and exits 141, `pipefail` makes the pipeline 141, and the `if` therefore evaluates
**false** — so a forbidden substring that **is** present is reported as **absent**. Reproduced on
this workstation: FOUND at 8/16/32/48/56 KiB, **MISSED at 64/72/96/128 KiB**. `$raw` is the whole
arm-1 server-committed dump, which grows with every beets release and every plugin enabled, and
the failure is **position-dependent** — a match near the top is missed, one near the bottom is
caught. `FORBIDDEN_BUILTIN=("Compilations" "/music/imported")` is the guard that proves no rule in
the effective config routes anything into a `Compilations/` tree or the retired import root, so a
false negative here is a green tick over a present condition: the exact defect class this whole
gap closure exists to remove.

Purpose: the fix is one construct per site, but the fix on its own is not the deliverable.
`--self-test` **structurally cannot** catch this defect today, because every synthetic dump it
feeds is a few hundred bytes. A fix with no test that crosses the ceiling leaves the next editor
free to reintroduce the pipeline. So this plan lands the fix **and** the case that would have
caught it, and proves that case discriminating by running it against the pre-fix code.

GC-13: `assert_beet_invocation_contract` funnels two distinct outcomes — "a real invocation in this
file's own source violates the D-04 contract" and "the synthetic negative was correctly rejected" —
into the single counter `ARM1_FAILS`, and case 6 compares that sum against the single expected total
`1`. "One real violation" + "the checker is blind" therefore sums to 1 and the case reports
`✅ … 1 red, as expected`. Two faults cancel into a pass. Contrived, but it is the same shape that
produces vacuous assertions everywhere else in this phase.

Output: a forbidden-substring scan with no pipeline in it, a seventh self-test case whose raw input
crosses 64 KiB, an independently-counted case 6, and one artifact holding every driven measurement
plus the repo-wide inventory of the remaining instances of the shape.
</objective>
