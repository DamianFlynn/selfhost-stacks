<objective>
Discharge criterion 4's Jellyfin half. Decide and apply the Jellyfin library option that makes both consumers read the same field, prove N distinct artist entities in Jellyfin's own API, and leave behind a standing assertion so the change cannot silently revert.

Purpose: CONF-04 is two claims — what beets writes, and what the consumers parse. D-34 took that decision: enable `PreferNonstandardArtistsTag`, do not enable `UseCustomTagDelimiters`. This plan applies it.

Output: the option enabled and field-by-field proven not to have disturbed the Phase 1 freeze; a before/after `ArtistItems` census committed; `check-music-consumers.sh` extended with both the flag assertion and the artist-entity check; the change recorded in `beets.md`.

This plan writes NOTHING into `/mnt/tank/media`. The only write is to Jellyfin's own configuration database, which is outside the `:ro` fence by construction.
