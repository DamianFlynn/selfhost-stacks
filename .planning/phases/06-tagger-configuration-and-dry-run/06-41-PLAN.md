Drive the one lever plan 06-03 named and never pulled: change the mtime of exactly three files, then
issue the already-proven-safe targeted Default-mode refresh, so Jellyfin's prober re-runs on those
three and reads the `ARTISTS` tag through the `PreferNonstandardArtistsTag` option that has been

and is recorded as one in 06-43 — it is NOT an argument for escalating to the forbidden mode.

Purpose: turn CONF-04's Jellyfin half from "awaiting Phase 7" into a measurement taken today.
Output: one committed artifact, `06-41-conf04-reprobe-drive.txt`, and one ZFS snapshot.

estate-wide (D-24, T-06-11 — Phase 1 measured it rewriting 83 of 91 `.nfo` with `SaveLocalMetadata`
already off). It is not issued here, it is not a fallback here, and if the touch does not move the
rows the correct next step is a recorded negative result, not a wider hammer. The only scan
endpoint this plan issues is `POST /Library/Media/Updated`, at FILE scope, exactly as plan 06-03
issued it and proved it safe.

⛔ THE SECOND FENCE. `SaveLocalMetadata`, `EnableRealtimeMonitor` and `SaveLyricsWithMedia` are OFF
on the Music library, permanently (Phase 1). None of them is re-enabled by this plan, not even
temporarily to make a measurement easier.
