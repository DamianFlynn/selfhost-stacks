Per-stratum expectations to get right:
- S1/S3: `<albumartist>/<album>/<NN> <title>.<ext>` with `NN` zero-padded to 2. For S3 assert the top level is the literal `Various Artists` — the exact string from `va_name`, case included — and that `Compilations` appears nowhere in the file.
- S2/S4: `<albumartist>/<album>/<DD>-<TT> <title>.<ext>`, both fields zero-padded to 2. **`02-05`, not `2-05`.** Note the choice and the third convention in the header: the existing library uses `CD 02-01 Artist - Title.ext`, Phase 6 does not reconcile the two, and this file is the statement of which convention Phase 7 will produce.
- S5: `DJ/<albumartist>/<album>/…` — the top-level `DJ/` sibling, not `Compilations/` and not an artist folder.

**The `%aunique{}` derivation, done explicitly rather than assumed empty.** For every sampled album, query the real library's `(albumartist, album)` pairs from Phase 1's 1,244-record snapshot. If exactly one album matches, `%aunique{}` renders empty and the path carries no bracket. If more than one matches, walk `aunique.disambiguators` in the configured order — `albumtype year label catalognum albumdisambig releasegroupdisambig` — and take the FIRST whose values are distinct across the ambiguous set; the rendered suffix is a leading space then the value in `[]`. Record, in the file header, every album where `%aunique{}` is predicted to fire and with which disambiguator — that list is D-16's "every folder where it fires is reported", captured at the earliest possible moment.

**The guard, and it is a hard one.** If no disambiguator separates an ambiguous set, beets appends the **numeric database id**, which is not reproducible across libraries and differs between a throwaway and the real one. Any committed expected tree containing such a value is a landmine. So: this file must contain **zero** occurrences of a bracketed token ` [N]` where N is an integer that is not a four-digit year in 1900–2099. If a sampled album would produce one, do **not** write the id — remove that album from the zero-diff set, replace it from its stratum's next eligible row by the same `LC_ALL=C` sort, and record the substitution in `06-SAMPLE.md`'s reallocation table with its reason. If the stratum cannot be refilled, quarantine that album to a named class assertion in plan 06-11 instead and say so in both files.

**State the library the tree assumes.** `%aunique{}` is evaluated against whatever library the item is in. This tree is computed against the **real** library's collision set (OQ-3 option (a)), so plan 06-11's oracle must run against a **copy** of the real `library.db`, opened by flask's 2.12.0 per D-04, with the original's sha256 asserted unchanged. Write that requirement into this file's header: the count is only meaningful with the library it was computed against attached.

Finish with a self-check recorded in the file: the line count equals the sampled audio-file count from `06-SAMPLE.md`, every line starts with `/media/Music/`, and the file is `LC_ALL=C` sorted.
