<objective>
Commit the three overturning thresholds and both measurement templates **before any evidence
exists**, so criterion 5 is met by git history rather than by assertion.

ROADMAP Phase 3 criterion 5 requires the pre-committed overturning thresholds to be written into
the plan before evidence collection. A threshold added or moved after the evidence fails that
criterion outright, and this project's own STATE.md names "the spike becomes tool advocacy" as the
Phase 3 drift risk. This plan is the fence against that.

It also commits the two corrections that must not be discovered later: **OD-2** (axis one is
measured at beets 2.13.1, axis two at whatever beets-flask ships, because beets-flask rc6 hard-pins
`beets==2.12.0`) and **OD-3** (the sample population is widened to `dj-mixes` ∪ `unsorted` **now**,
before evidence, precisely so the ~40% threshold is bound to the population it will be measured on).

It also commits the **estimator** T1 is tested against. The plan-03-03 sample is stratified and
deliberately never random; it is a coverage sample built to surface failure modes, and a coverage
sample is not a population estimate. So T1's rate is defined **here** as a per-stratum roll-up
weighted by each stratum's prevalence across the committed 143-folder backlog. The **threshold value
stays 40%** — only the estimator is being specified, and it is specified before any weight, any rate
and any evidence exists.

This plan runs in **wave 1**, with no dependency on plan 03-01. It writes two Markdown files: it
needs no disk headroom, no container and no image, so nothing in 03-01's OD-1 gate is a precondition
for it. Moving it to wave 1 is what lets plan 03-03 depend on it — the sample must not be drawn
before the thresholds and the estimator that govern it are committed — without adding a ninth wave.
If 03-01's disk gate fails and the phase halts, these two documents having already been committed
costs nothing and strengthens criterion 5's ordering rather than weakening it.

Purpose: criterion 5 is unprovable retroactively. The only evidence that a threshold predated the
number is a commit that predates the number's commit — and that commit must be on `origin`, because
a local branch can be amended or rebased.
Output: `03-DECISION.md` (skeleton, thresholds populated, results empty) and
`03-ERGONOMICS-SHEET.md` (template, every measurement cell empty).
</objective>
