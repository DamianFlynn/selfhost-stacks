## Deviations from Plan

1. **[Rule 1 - Bug] Hold-name verification would make every run red.** `beets` is `run --rm` only
   (`profiles: ["manual"]`, commented out of the arrs include list), so no container named `beets`
   exists. Built-in hold names now also pass when the repo declares that `container_name:`. A name
   matching neither is still fatal. `DEPLOY_HOLD_EXTRA` names must match a container.
2. **[Rule 2] Media-class names that match no container produce a warning (not fatal).** A rename
   would otherwise deploy outside the window without anyone noticing.
3. **Refused is not a counted failure.** It has exit 3 and its own gauge. `FAILURES` stays 0, so
   `failed_stacks` does not double-page.
4. **Additional `guard-deferred` counter.** Stacks not attempted after a disk-guard trip are pending,
   not failed, and are included in `selfhost_deploy_pending_services`.
5. **Plan verify not met as written:** radarr and immich_kiosk are absent from the real dry-run
   transcript because the concurrent session had deployed them (see above). Covered by the fixture.
6. STATE.md and ROADMAP.md were not updated. This is a quick task, the SUMMARY is left uncommitted
   as instructed, and the orchestrator owns the state.
